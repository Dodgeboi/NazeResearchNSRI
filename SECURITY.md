# Security boundary

This repository contains a defensive simulator, not offensive security tooling. It does not scan networks, exploit software, store credentials, or connect to hospital systems.

Please use GitHub Issues for ordinary bugs and reproducibility questions. Do **not** place any of the following in an issue, pull request, discussion, or uploaded file:

- patient or employee information;
- credentials, tokens, or private keys;
- IP addresses or real network diagrams;
- unpatched vulnerabilities or exploit details;
- security logs from a real organization;
- vendor weaknesses that are not already public; or
- information about an active incident.

If a report cannot be made safely without sensitive information, do not submit it through this repository. Contact the affected organization through its established security-reporting process instead.

The synthetic model should not be used to probe, rank, or make claims about a real hospital without that organization's authorization.
